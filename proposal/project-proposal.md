# Project Proposal

## Title
**Predicting International Football Match Outcomes Using Machine Learning**

## Research Question
How accurately can machine learning models predict international football match outcomes using historical team performance and match context?

## Proposal

This project aims to investigate the application of machine learning techniques in predicting the outcomes of international football matches. Using the International Football Results dataset, which contains historical match records dating back to 1872, we will explore factors that may influence match outcomes, such as recent team performance, home advantage and tournament type.

We plan to perform exploratory data analysis to identify historical trends and patterns before developing predictive models. Relevant features will be engineered using historical match records, including each team's recent performance over its previous five matches.

We will implement and compare Logistic Regression and Random Forest classification models to predict three possible outcomes: home win, draw and away win. Model performance will be evaluated using accuracy, precision, recall, F1-score and confusion matrices.

Through this project, we aim to understand how machine learning can be applied to football match prediction and investigate which factors contribute to prediction performance.

## Project Scope
- Dataset: International Football Results
- Task: Three-class classification
- Models: Logistic Regression and Random Forest
- Evaluation: Accuracy, precision, recall and F1-score

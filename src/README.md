# Source Code

## Overview
This folder contains the Python source code used to implement the machine learning workflow for predicting international football match outcomes.

## Planned Components

- **Data Preprocessing:** Load, clean and prepare historical football match data.
- **Feature Engineering:** Generate predictive features such as recent team performance and home advantage.
- **Model Training:** Implement Logistic Regression and Random Forest classification models.
- **Model Evaluation:** Evaluate and compare model performance using appropriate classification metrics.

## Planned Files

| Filename | Description |
|---|---|
| `preprocessing.py` | Data cleaning and preprocessing |
| `feature_engineering.py` | Creation of predictive features |
| `train.py` | Training machine learning models |
| `evaluate.py` | Model evaluation and comparison |

*Note: These files will be added as the project progresses.*

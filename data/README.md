# Dataset

## Source
International Football Results dataset, obtained from Kaggle.

## Files

| Filename | Description |
|---|---|
| results.csv | Historical international football match results |
| goalscorers.csv | Goal scoring records |
| shootouts.csv | Penalty shootout information |
| former_names.csv | Historical team names |

## Main Dataset
Our primary analysis will focus on `results.csv`, which contains historical international football match records.

The other CSV files may be explored if they are relevant to our research.

## Data Usage
The dataset will be used for exploratory data analysis, feature engineering, machine learning model training and evaluation.

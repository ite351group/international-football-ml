# Predicting International Football Match Outcomes Using Machine Learning

## Project Overview
This project investigates the use of machine learning techniques
to predict the outcomes of international football matches using
historical match data.

## Research Question
How accurately can machine learning models predict international
football match outcomes using historical team performance and
match context?

## Dataset
International Football Results (1872–2026), obtained from Kaggle.

## Objectives
- Explore historical international football match trends.
- Investigate the influence of home advantage and recent team form.
- Develop machine learning models to predict match outcomes.
- Compare the performance of different classification algorithms.

## Planned Methods
- Logistic Regression
- Random Forest
- Model evaluation using accuracy, precision, recall and F1-score

## Repository Structure
- `proposal/` – Project proposal and research idea.
- `data/` – Dataset information.
- `notebooks/` – Data analysis and machine learning experiments.
- `src/` – Python source code.
- `results/` – Visualisations and model evaluation results.
